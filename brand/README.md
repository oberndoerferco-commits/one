# PA & CO — logo

Vector versions traced from the client's logo (the "Limited Edition" line removed).

| File | Use |
|---|---|
| `pa-co-logo.svg` | Stacked: diamond above the wordmark |
| `pa-co-logo-horizontal.svg` | Diamond left of the wordmark (website header) |
| `pa-co-diamond.svg` | Diamond mark alone (favicon, small spaces) |
| `pa-co-wordmark.svg` | Wordmark alone |

All files are single-colour black paths; change the `fill` to recolour.
The source image was 531 × 354 px, so the paths were traced at 8× with smoothing.
