Run the Monday review for Oberndörfer Milano.

Use the `analyst` agent. It must:

1. Pull the last 7 days and the last 90 days: sessions, cart additions,
   checkout reaches, completed orders, revenue.
2. **Filter the bots** — exclude `/password` landings, discount the
   direct/US block, and say what was excluded.
3. Compare against the prior period and against the twelve-month baseline
   (8,601 sessions → 158 cart adds → 1 order at €10).
4. Report which blog articles drew traffic and which products were viewed.
5. Write the review to `docs/handbook/reviews/<today>.md`.

Then, as chief of staff, give me:

- One paragraph on what actually changed. Plain sentences.
- A small funnel table.
- **One recommended move for this week**, with the agent who would do it and
  roughly what it costs in time. Not a menu — one move.

If nothing meaningful changed, say so in one line rather than padding it.
