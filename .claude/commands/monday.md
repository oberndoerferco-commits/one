Run the Monday review.

`performance-analyst` first. It must:

1. Pull the last 7 days and the last 90 days: sessions, cart additions,
   checkout reached, orders, revenue.
2. **Filter the bots** — exclude `/password` landings, discount the direct/US
   block, and state what was excluded.
3. Compare against the prior period and the twelve-month baseline
   (8,601 sessions → 158 cart additions → 139 checkout → 1 order at €10).
4. Report which journal pieces drew traffic and which pieces were viewed.
5. File the review to `docs/handbook/reviews/<today>.md`.

Then `co-founder` gives me:

- One paragraph on what actually changed. Plain sentences.
- A small funnel table.
- **One move for this week**, the person who owns it, and roughly what it costs
  in time. One move, not a menu.

If nothing meaningful changed, say so in a line rather than padding it.
