The one thing no agent can do

Name the leather.

Poltrona Frau has Pelle Frau®. Serapian has Mosaico. An unnamed hide is a commodity; a named one is proprietary — and it changes every product page in the catalogue at once.

It was already identified in the copy review as the highest-leverage change available to the whole house. It needs your decision, not an agent's.

Every agent inherits CLAUDE.md — the maison voice, the retire list, and six guardrails: nothing touches the live theme, no price changes, no deletions, no posting, no sending, no spending without you saying so.
