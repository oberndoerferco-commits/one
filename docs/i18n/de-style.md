# German translation rules – Oberndörfer Milano (12 November 2026)

Source of truth is always the CURRENT English text. Translate it faithfully: same facts, nothing added,
nothing dropped. Never invent materials, origin, sizes or claims.

## Voice
- Sie-form. Short, factual, calm. No marketing fluff ("Herz der Mode", "Luxus pur", exclamation marks).
- Natural German word order, as a German luxury shop would write it, not word-for-word.
- "Made in Italy" / "handgefertigt in Italien" only where the English says it. "handcrafted in Milan" →
  "in Mailand von Hand gefertigt".
- Brand name always "Oberndörfer Milano". Never "Oberndörfer & Co" / "& CO".
- Keep product names that are names: "OM", "Progetto Campione", "Model 017", "SAC", "Trax NYC",
  "The Mirror Handbag", "Vault Bag".
