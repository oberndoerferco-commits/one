# Italian translation rules – Oberndörfer Milano (14 November 2026)

Source of truth is always the CURRENT English text. Translate it faithfully: same facts, nothing added,
nothing dropped. Never invent materials, origin, sizes or claims.

## Voice
- Lei-form for the customer ("Le scriviamo", "può"), or impersonal where natural. Short, factual, calm.
  No fluff ("eccellenza senza tempo", "lusso assoluto", exclamation marks).
- Natural Italian, as an Italian luxury maison would write it, not word-for-word.
- "Made in Italy" / "fatto a mano in Italia" only where the English says it. "handcrafted in Milan" →
  "realizzato a mano a Milano".
- Brand name always "Oberndörfer Milano". Never "Oberndörfer & Co" / "& CO".
- Keep names that are names: "OM", "Progetto Campione", "Model 017", "SAC", "Trax NYC", "The Mirror Handbag",
  "Vault Bag", "Ready to Wear".
